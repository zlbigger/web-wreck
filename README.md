# WEB / WRECK · 网页破坏游乐场

把熟悉的网站变成一张可以跳跃、飞行、开火的游戏地图。

打开页面，一名像素装甲兵就站在你的网页上。书法标题可以当落脚点，图片可以当平台；拿起激光炮切开页面，用喷火器灼烧文字，或者扔一颗手榴弹，看网页碎片带着原来的图案飞散。

**在线试玩：[zlbigger.com/gan/](https://zlbigger.com/gan/)**

![游戏界面：六种武器与真实网页破坏](docs/images/gameplay.png)

## 玩法亮点

- **真实网站外观**：使用 zlbigger.com 的完整网页快照，保留原站的书法、人物插画、导航和排版，全窗口沉浸式呈现。
- **网页就是关卡**：文字、图片可以作为单向平台，能跳上去、站上去；支撑位置被打穿，小人就会掉下去。
- **六种武器**：冲锋枪、霰弹枪、火箭筒、激光炮、喷火器、手榴弹。
- **不同的破坏反馈**：细小弹孔、扇形散射、光束切割、持续火焰、延时爆炸，以及不规则缺口、焦边、裂纹和带原图纹理的碎片。
- **独立合成音效**：每种武器有不同的声音，武器栏支持静音。
- **自由探索**：跳跃、喷气飞行、整页滚动、全屏、暂停与一键重建；提供移动端触控按钮，推荐电脑键鼠体验。

## 操作

| 操作 | 按键 |
| --- | --- |
| 左右移动 | A / D 或左右方向键 |
| 跳跃 / 喷气飞行 | 空格、W 或上方向键；长按启动喷气 |
| 穿过平台 | S 或下方向键 |
| 瞄准 / 开火 | 移动鼠标 / 按住左键 |
| 切换武器 | 1–6，或点击右下角武器栏 |
| 投掷手榴弹 | 选择武器 6 后左键；也支持右键快捷投掷 |
| 浏览整页 | 滚轮、PageUp / PageDown 或右侧箭头 |
| 重建网页 | R |
| 暂停 / 恢复 | Esc |
| 全屏 / 声音 | 点击对应悬浮按钮 |

## 本地运行

需要 Node.js 20.19+ 或 22.12+（建议使用当前 LTS）。

```bash
npm install
npm run dev -- --port 5173
```

打开 `http://127.0.0.1:5173/`。

## 构建与部署

部署到域名根路径：

```bash
npm run build
```

部署到演示站同样的 `/gan/` 子目录：

```bash
npm run build -- --base=/gan/
```

将 `dist/` 中的文件上传到网站对应目录即可。网页图片路径自动跟随构建的 base，无需后端或数据库。

## 技术实现

原生 JavaScript + Canvas 2D + Vite，音效使用 Web Audio API 实时合成。

- 网页快照绘制到离屏画布，不规则多边形擦除产生真实缺口。
- CPU 扫描线更新碰撞遮罩，避免射击时反复读取 GPU 像素。
- 碎片保留命中位置的网页纹理，并模拟旋转、重力和淡出。
- 背景与音效噪声缓存，界面更新节流，屏幕外粒子跳过绘制。
- 平台根据首页元素位置及下方内容像素生成，属于轻量游戏碰撞近似。

```text
src/main.js          游戏循环、武器、角色、声音与渲染
src/platforms.js     平台生成与落地判定
src/damage.js        不规则破坏区域的碰撞遮罩
src/style.css        全窗口界面和触控布局
public/captures/     游戏使用的真实网页快照
docs/images/         README 界面截图
```

## 当前边界

这是单人网页游戏原型。默认素材是 **2026-09-29 抓取的 zlbigger.com 网页快照**，不会实时抓取网页，不会改变或损坏真实网站，也不包含联网多人功能。

更换目标网站需要替换快照，并调整首页平台坐标。网页中的链接是快照画面，不是可点击的原站链接。截图、人物照片和站点视觉素材来自 zlbigger.com，不应视为第三方素材授权。
